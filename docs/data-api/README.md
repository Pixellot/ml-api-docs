# Data API

The Data API provides JSON Schema specifications for ML-generated highlights data. Schemas, glossaries, and integration guides are organized per sport:

- **[Basketball](../basketball/specification.md)** - Player-based highlights (shots, assists, rebounds)
- **[Outdoor Football](../outdoor-football/specification.md)** - Team-based highlights (plays, scoring, stats)

- [Support](guides/support.md) - Contact information for technical integration assistance
