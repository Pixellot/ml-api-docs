# ML Highlights API Documentation

This repository contains the official API documentation for Pixellot's ML Player Highlights service, which automatically analyzes basketball and outdoor football games to identify and timestamp individual player and team highlights.

## Overview

The ML Highlights API provides structured data about key basketball and outdoor football moments detected through automated video analysis. The service identifies player and team actions, associating them with specific players or teams and providing precise timing information within the game footage.

## API Schema

The current API schema version is `v1.2.0`. Each sport has its own self-contained schema:

- Basketball: [basketball.schema.json](basketball.schema.json)
- Outdoor Football: [outdoor-football.schema.json](outdoor-football.schema.json)
